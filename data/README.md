# Data

The raw CSV is not committed to this repository. Download the public building
FDD data from the U.S. Department of Energy catalog and place the prepared file
at:

```text
data/RTU_CLEAN_faultandnofault.csv
```

Official dataset record:

- https://catalog.data.gov/dataset/data-sets-for-evaluation-of-building-fault-detection-and-diagnostics-algorithms
- DOI: https://doi.org/10.25984/1824861

The catalog identifies the data as public and licensed under CC BY 4.0. The
prepared CSV used in this project contains 30,240 one-minute observations, 69
columns, ten room-temperature targets, and a binary ground-truth field used
only for retrospective evaluation.
